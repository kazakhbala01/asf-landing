# Передача проекта — сайт ASF (Astana Soap Factory)

Документ для того, кто продолжит работу над сайтом.

## Что это

Одностраничный сайт производителя автохимии ASF: каталог из 16 позиций,
блоки продаж (выгоды, сравнение, до/после, отзывы, FAQ), заявки через WhatsApp.

- **Продакшен:** https://www.astanasoapfactory.com
- **Репозиторий:** https://github.com/kazakhbala01/asf-landing (приватный)
- **Хостинг:** Vercel (автодеплой из ветки `main`)

## Стек

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 4.
Сайт полностью статический: нет бэкенда, базы и админки. Заявки уходят
в WhatsApp через ссылку `wa.me` с заранее подставленным текстом.

## Быстрый старт

```bash
git clone https://github.com/kazakhbala01/asf-landing.git
cd asf-landing
npm install
npm run dev
```

Открыть http://localhost:3000

Сборка: `npm run build`

## Деплой

Любой push в `main` → Vercel собирает и выкатывает автоматически.
Отдельных команд не нужно.

## Фотографии и видео

Все обработанные файлы лежат в `public/` и закоммичены в git:

- `public/products/` — фото товаров (13 шт., белый фон, 1200×680)
- `public/photos/` — hero, до/после, производство, основатель, брендовые
- `public/media/` — видео и креативы для ленты «ASF в деле»

Чтобы добавить товар с фото: положить снимок в `public/products/<id>.jpg`
и указать путь в поле `image` товара. Без `image` рисуется SVG-канистра
(`components/Canister.tsx`) — сейчас так только у `motor-cleaner`.

**Исходники (не в репозитории)** — их нужно передать отдельно, если
понадобится перекадрировать:
`Desktop/creative` (30 файлов), `Desktop/products` (13 файлов),
каталог `Каталог.pdf` и логотип `Untitled design.pdf`.

## Что осталось незакрытым

Подробный чек-лист — в `README.md`. Кратко:

1. **Цифры клиента не проверены** — 4,1 млрд ₸, 1000+ компаний, 94%, 89%
   (`components/Intro.tsx`). Клиент подтвердил, что уверен в них, но
   документального подтверждения нет.
2. **Юридические документы** — есть только черновик политики
   конфиденциальности (`app/privacy/page.tsx`). Реквизиты, сертификаты,
   пользовательское соглашение клиент не присылал.
3. **Аналитика не подключена** — код готов (`components/Analytics.tsx`),
   нужны ID: `NEXT_PUBLIC_GA_ID`, `NEXT_PUBLIC_YM_ID`,
   `NEXT_PUBLIC_META_PIXEL_ID` в переменных окружения Vercel.
4. **Нормы разведения** отсутствуют у AutoGleam Premium и Hydro Shield —
   в каталоге вместо таблицы стоит «Подберём под ваше оборудование».
5. **SEO** — сделаны только базовые мета-теги и Organization-разметка.
   Нет sitemap, robots, OG-картинки, страниц под категории и товары,
   казахской версии.
6. **Отзывы** — реальные, взяты из карточек Kaspi. Фото клиентов и
   видеоотзывов нет.

## Подводные камни

- **Кеш картинок Next.** Если заменить файл в `public/`, оставив то же имя,
  локально будет отдаваться старая версия. Лечится `rm -rf .next` и
  перезапуском. На Vercel проблемы нет — там сборка с нуля.
- **Не запускать `npm run build` при работающем `npm run dev`** — они
  пишут в одну папку `.next` и портят друг другу кеш.
- **Email коммитов.** Vercel отклоняет деплой, если автор коммита не
  привязан к аккаунту. В репозитории уже настроено
  `user.email = amnbyalms@gmail.com`; новому человеку нужно поставить свой,
  привязанный к его GitHub.
- **Анимации появления** сделаны на CSS `animation-timeline: view()`.
  В старых браузерах просто не срабатывают — это нормально, контент виден.
